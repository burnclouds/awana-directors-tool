1.51.19bNov 20

built 2026-11-20; live on GitHub Pages once pushed

Every leader should press Update now.

  • Notes and replies on To do (BACKLOG N49). Edit now opens only the note's own text, in a large box, with its line breaks; before, it opened the note and all its replies as one text and saving wrote them back into the note. A reply is a message of its own: each has its own Edit and Remove (Remove can be undone), and Save reply and Cancel sit below the reply box. Debug, Records that look wrong, lists any note that already holds the text of its reply, so notes damaged by the old Edit can be found and tidied by hand.
  • Attendance sheets (N50, Cubbies). Every row is numbered, the blank write-in rows too, and page 2 of a big class carries on at 21. On the Cubbies sheet each night has four sub-cells: the first headed Attendance (filled from the record) and three with blank headings left for writing in; a recorded Extra no longer prints on the Cubbies sheet (the data is kept).
  • Printing (N51, N53, N54). An explanation of how to read a report no longer prints under its title (Dates attended, Game standings, End-of-year awards, Planning Center changes, the Pace Watch definitions); the printed date, the Planning Center data date, tallies and cautions still do. The coaches color teams list is color blocks in two columns with the same layout for both groups, so each group fits one page; the printed date is at the right end of the title line; the column headings are gone; and it follows the List order picker (the default is Color, then first name, so it prints first name first where it used to print last name first). Game standings no longer has a Group picker: it prints Sparks and T&T, one page each, and Choose pages picks.
  • Sparks progress sheet (N56). The left labels are Section 1 to Section 8 and Review 1 to Review 8. The award cells at the right drop the word Jewel (Green 1, Red 2, ...), and the Pilot Wing and Red Jewel 1 are one cell, Wings/Red 1 (earned until both are given, then given with the later date). The two bands at the left (Book award, Review emblem) share one column. Every box carries a 6 pt grey init and date caption, and every date prints in full as mm/dd/yy.
  • One Progress sheets report; blank sheets (N57). The Reports list has one Progress sheets report, with a Books box: Current book (class binders), Every book started (records files) (what the Achievement record printed: a page for every book a child has started) or Blank sheets, with a Blank sheets per class count (3 unless you change it). A blank has the class and club year printed and a write-in name and book, for Cubbies, Sparks and T&T. Achievement records is no longer a report of its own (a saved bundle that names it still prints, and a child's Print record on the Person tab opens Progress sheets with every book). Print class binders has Blank progress sheets after each class's sheets (3; 0 for none). A Child box prints one child's sheets.
  • Progress sheet on screen (N58). A completed section is clearly shaded in light mode as well as dark mode, and so are its date boxes.
1.51.19Nov 20

built 2026-11-20; live on GitHub Pages once pushed

Every leader should press Update now.

  • Only the pages that are hole-punched keep a punch margin (BACKLOG N47). Attendance sheets (punched along the top), progress sheets and achievement records are the pages that go in the binder; everything else goes in a page protector and now uses the whole page.   • The version history page is redesigned. Lists no longer staircase to the right, italics and code show as formatting instead of asterisks and backticks, each version has a short title with its date, versions are grouped into series (1.51, 1.50, earlier) with the three newest open and the rest folded, there is a collapsed index of every version, and it works on a phone, in dark mode and in print.

built and pushed 2026-11-19; live on GitHub Pages

Every leader should press Update now: an older copy keeps working but does not show the new Debug sections or the changes to printing.

  • Debug: Records that look wrong, and Readable copy (BACKLOG N39, N40). Check the file lists records that do not add up, with the child's name: a handbook for another class's book; a received date or sign-offs for a book that is not in the book list or belongs to another group; a note about a child who left the roster or a book that is gone; a color that is not Red, Blue, Green or Yellow; the same award listed twice in a night or announced on two nights. Checking only looks. A fix button appears only where the fix loses nothing (a bare handbook code for another group's book; a repeated award in one night's list); everything that holds a date, a note or a color is shown and left alone. Readable copy writes a second, read-only JSON with the codes spelled out (Planning Center fields by name, attendance marks as words, handbooks as code/date/note, a name beside every child id); it goes to this computer, never Google Drive, the app refuses to open it, and the data file is unchanged. docs/DATA-FORMAT.md section 16 is the matching decoder page.   • Printing (BACKLOG N37). Binder pages print with a 0.85 in left margin for a three-hole punch. No heading ends a page and no table row is split across two. Screen help (the No photos instruction, the Books source note, three paragraphs on Statistics, the empty "Statistics for:" label) no longer prints. The "* = changes team" note prints only when a child on the page carries a "*". Statistics shows the year once. Phone numbers on the emergency pages print as (ddd) ddd-dddd. Awards earned prints the year once. A report with nothing to print (Planning Center changes, End-of-year awards, Pace Watch with no dates) greys out Print instead of printing an empty page. On the everyone-by-name page and the volunteer list a class such as "T&T Girls (Group A)" stays on one line, and the team column heading reads "Q2 Team" (was "Q2 Color Team"). On the coaches notes sheet a theme word is made smaller to fit its column instead of being broken in the middle. A flag made on a filter (Night, Class, Group, Team, Type, Sort) remembers it, the To do list names its value, and Go sets the filter back first. Line breaks typed in a note, flag or reply are kept.
  • Save button. The Google Drive saving icon replaces the label while a save runs, so the header does not move.
  • Fixes found by a code review before release. Debug's Records that look wrong no longer judges a Puggles, Volunteers or unassigned child on class (it could have offered to clear a valid handbook code). A coaches notes page that is not the first page of a printout keeps its 0.85 in punch margin, and the hidden "nothing to print" pages no longer decide the orientation of a printout. Replies written on the same day on a note show in a fixed order, and History says "reply added" for a reply on an ordinary note. The Statistics subtitle checks for the whole season in the club name, not a stray digit pair.
