## Code review of the unreleased code (2026-11-19, medium effort, `9a0aeb6..HEAD`)

Ten findings; each was checked against the code before acting. **Eight were real and are fixed, each with a test that failed first:**
- Debug "Records that look wrong": a Puggles, Volunteers or unrecognised-room child was judged on class (the app's group answer is never empty for those), so a valid handbook could be listed and its bare code offered for clearing. Only Cubbies, Sparks and T&T are judged now.
- Printing: the named page for a notes sheet that is not first (for example in a bundle) hard-coded a 0.25 in margin and lost the 0.85 in punch margin; and `setPageStyle` still counted the hidden "nothing to print" placeholder pages when choosing orientation and margins. Both fixed.
- To do: replies written on the same day were shown in file-key order; they now use the same order as a bug report (date, then reply id).
- History: a reply on an ordinary note was a generic "Notes and flags changed"; it now says "reply added: text".
- Statistics subtitle: "is the year already in the club name" is now a whole-season test, not a substring.
- Readable copy: a `blueDrops` entry that is not `gem|day` is kept as written instead of becoming NaN.
- A comment that had slipped onto the wrong line in `addFlag` is back beside the line it describes.

**Two were left as they are, on purpose:** (1) phone numbers: every phone-shaped number in an emergency cell is reformatted (display only); a 10-digit run that is not a phone number is not expected in those fields, and the stored value is untouched. (2) A note made on a filter control is listed in the flag dialog for that control whatever value the filter now has: the note belongs to the control, and the stored value only tells Go what to set back.
